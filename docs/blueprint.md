# **App Name**: InfraGuard

## Core Features:

- Real-time Alert Aggregation: Collect and process infrastructure alerts from multiple external sources (NOAA, Open511, USGS, NBI, FIRMS) within defined geographical regions.
- Geospatial Alert Visualization: Display aggregated infrastructure alerts on an interactive map interface, allowing users to visually identify affected areas.
- Filtered Alert Feed: Present a personalized feed of infrastructure alerts based on user-defined regional interests and alert types.
- Persistent Alert History: Store a comprehensive history of all fetched alerts for review and analysis in a database.
- Alert Summary Tool: Utilize generative AI to summarize complex alert descriptions into concise, easy-to-understand bulletins for quick assessment.
- In-App Notifications: Provide immediate in-app notifications for newly detected or updated critical infrastructure alerts.

## Style Guidelines:

- Primary color: A strong, dependable blue (#2686D9) for calls to action and highlighting alert prominence.
- Background color: A subtle, dark blue-gray (#192227) for a sophisticated and focused interface, reducing eye strain.
- Accent color: A vibrant cyan (#19E6E6) to highlight active statuses and draw attention to critical updates or interactive elements.
- Body and headline font: 'Inter' (sans-serif) for all text elements, ensuring excellent readability and a clean, modern aesthetic suitable for data display.
- Use clear, outline-style vector icons that effectively differentiate between various alert types (e.g., weather, road closures, bridge conditions) and critical statuses.
- A responsive, modular dashboard layout featuring a central interactive map view and collapsable sidebars for detailed alert lists, filters, and user settings.
- Subtle animations for loading states, smooth transitions between map interactions and alert detail views, and a gentle pulse effect for new critical alerts to draw user attention without distraction.
